What the email scrubber checks

Duplicates + syntax
Removes repeats and malformed addresses before any network work.
Disposable domains
Loads a large public disposable-domain blocklist, with a built-in fallback list.
Domain typo detection
Flags likely misspellings of major providers such as gmail.com and yahoo.com.
NXDOMAIN + Null MX
Rejects nonexistent domains and domains explicitly declaring that they accept no email.
A / AAAA fallback
Does not hard-reject a domain merely because it has no MX record if a mail fallback host exists.
Dead-provider + placeholder patterns
Flags retired providers, fake/test addresses, and obvious junk local-parts.
Role + no-reply accounts
Role accounts become Questionable; no-reply mailboxes are rejected.
Catch-all signal
Flags known catch-all domains now; the rule is structured so SMTP catch-all probing can plug in later.
Provider classification
Records common mail providers from MX data for later provider-specific SMTP behavior.
Audit signals
Exports every triggered rule so we can tune categories instead of hard-coding individual addresses.
Email verification happens in two stages: the first pass removes cheap failures in your browser. Deep Verify then asks DockLight's Outpost SMTP worker whether surviving mailboxes are accepted, rejected, catch-all, or inconclusive. No message body is sent.
Why scrub first?

Pay premium verification rates only on the addresses that survive.

Most email verifiers charge per address checked. DockLight's first pass removes duplicates, malformed addresses, disposable domains, dead domains, and other obvious failures before you spend a paid verification credit on them.
